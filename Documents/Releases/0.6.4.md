Inspector 0.6.4 refines process tables and reduces package size.

- Process and detail tables use more compact memory values, clearer CPU headings, and better-aligned headers and sort indicators. The process list shows the user when space allows, while VoiceOver retains full units.
- Release packages remove unused bitcode and redundant icon assets while preserving all image scales for iPhone and iPad.
- Packaging checks now reject LaunchDaemon paths without an explicit root, and the depiction changelog uses a pinned update script.

Choose `iphoneos-arm64e` for custom firmware with a roothide bootstrap or `iphoneos-arm64` for rootless (`/var/jb`). SHA-256 checksums are included in `SHA256SUMS`.
