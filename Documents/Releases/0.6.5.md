Inspector 0.6.5 prepares a data folder of its own when it is installed.

- Installing the package now creates `Documents/wiki.qaq.Inspector` for mobile — and `Documents` itself where the bootstrap had none — so Inspector has a folder no other app writes into, as a sandboxed app would. Nothing else changes.

Choose `iphoneos-arm64e` for custom firmware with a roothide bootstrap or `iphoneos-arm64` for rootless (`/var/jb`). SHA-256 checksums are included in `SHA256SUMS`.
